하루 한 패턴 영어

듣기 속도 목소리
발음이 기계 같다면? 더 자연스러운 목소리 설치하기

발음은 이 기기(컴퓨터·휴대폰)에 설치된 음성을 써요. 목소리 목록에서 Premium · Enhanced · Natural · Online이 붙은 음성이 가장 자연스러워요.

Mac: 시스템 설정 → 손쉬운 사용 → 읽기 및 말하기 → 시스템 음성 옆 ⓘ (음성 관리) → 영어(미국)에서 Ava (Premium), Zoe (Premium) 또는 Evan (Enhanced) 다운로드 → 이 페이지 새로고침.

설치했는데 목록에 없다면: 브라우저는 켜질 때 한 번만 목소리 목록을 읽어서, 페이지 새로고침으로는 새 목소리가 안 보여요. 브라우저를 ⌘Q로 완전히 종료한 뒤 다시 열어 주세요. Chrome은 Premium 음성을 못 불러오는 경우가 있어서, 그래도 없으면 Safari에서 열어 보세요.

Windows: Microsoft Edge로 열면 Microsoft Ava/Andrew Online (Natural) 음성을 바로 쓸 수 있어요.

목소리를 바꿔도 같은 소리가 난다면: 지금 열어 둔 프로그램이 목소리 선택을 무시하고 시스템 기본 음성만 쓰는 것이에요 (Claude 데스크톱 앱이나 Cursor 같은 앱 안에서 자주 생겨요). 이 페이지를 Chrome이나 Safari에서 열어 주세요.

iPhone · iPad: 설정 → 손쉬운 사용 → 읽기 및 말하기 → 음성 → 영어 → Ava/Zoe (향상된 음질) 다운로드 → 이 페이지를 다시 열고 목록에서 고르기. 아이폰은 Chrome에서 열어도 Safari와 같은 음성을 써요.

안드로이드: 설정 → 접근성(또는 일반) → 텍스트 음성 변환 출력 → 기본 엔진을 Google 음성 서비스로 → 언어를 영어(미국)로 → 음성 데이터 설치에서 원하는 목소리 고르기. 안드로이드 Chrome은 목록에서 골라도 휴대폰에 설정한 목소리로 읽는 경우가 많아요.

소리가 아예 안 나면: 휴대폰 무음 모드(옆면 스위치)와 미디어 볼륨을 확인해 주세요. 화면이 꺼지면 읽기가 멈춰요.
